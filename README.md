# 森下工務店 Webサイト（スマホ表示の修正サンプル）

スマホ対応していない工務店サイトを、スマホで見やすく直したサンプルです。会社名・住所・電話番号・施工事例はすべて架空のものです。

- 修正後: https://mashite792.github.io/morishita-koumuten/
- 修正前: https://mashite792.github.io/morishita-koumuten/before/

スマホ、またはブラウザの開発者ツールのスマホ表示で、2つを見比べてください。

## ご依頼内容

> 森下工務店の森下です。
> お客様から「スマホでホームページが見づらい」と言われることが増えました。
>
> - スマホで開くと文字がとても小さく、拡大すると横にスクロールしないと読めない
> - 施工事例の表が画面からはみ出す
> - スマホから電話番号を押したら、そのまま電話をかけられるようにしたい
>
> パソコンで見たときの雰囲気は、今のままで大丈夫です。

## 原因

| 症状 | 原因 |
|---|---|
| 文字がとても小さい | `<meta name="viewport">` が無く、スマホがパソコン用の幅（約980px）で縮小表示していた |
| 横スクロールが出る | サイト全体・表・画像の幅が `1000px` や `880px` で固定されていた |
| 表がはみ出す | 6列の表で、さらに `white-space: nowrap`（折り返し禁止）が指定されていた |

## 対応内容

| 修正ファイル | 内容 |
|---|---|
| index.html | viewport の指定を追加。電話番号を押すと電話がかかるリンク（`tel:`）に変更。スマホの画面下に固定の「電話で相談する」ボタンを追加 |
| style.css | 固定幅を `max-width` に変更し、`float` による横並びを flex / grid に置き換え |
| style.css | スマホでは、ナビを3列×2段、「家づくりの想い」を写真と文章の縦並び、家づくりの流れを縦並びに変更 |
| style.css | 施工事例の表を、スマホでは1件ずつのカード表示に組み替え（パソコンでは表のまま） |
| style.css | スマホの文字サイズを 13px → 15px に拡大 |

パソコンでの見た目は、修正前と同じになるようにしています。
