# 森下工務店 Webサイト（スマホ表示の修正サンプル）

スマホ対応していない工務店サイトを、スマホで見やすく直したサンプルです。会社名・住所・電話番号・施工事例はすべて架空のものです。

- 修正後: https://mashite792.github.io/morishita-koumuten/
- 修正前: https://mashite792.github.io/morishita-koumuten/before/

スマホ、またはブラウザの開発者ツールのスマホ表示で、2つを見比べてください。

## ご依頼内容
